# Kigali Road Simulation

## Project Overview
This project simulates a car travelling from ALU Rwanda to Kigali Convention Center using Python.

The road contains 34 segments, with each segment representing 100 metres. The simulation responds to different road signs, including speed limits, zebra crossings, and bus signs.

## Features
- Validates road signs.
- Identifies different types of road signs.
- Adjusts vehicle speed according to speed limits.
- Stops at zebra crossings.
- Counts road signs.
- Validates user input.
- Inserts and replaces road signs.
- Calculates journey distance and summary.

## Project Files
- `road_simulation.py` – Contains the completed TODO 1–10 functions.
- `transit_program.py` – Runs the simulation.
- `engine.py` – Provides the simulation engine.
- `index.html` – Provides the browser interface.

## Requirements
- Python 3
- A web browser

## How to Run
1. Open the project directory.
2. Run the following command:

   ```bash
   python3 road_simulation.py
   ```

3. Follow the instructions in the terminal to start the simulation.

## Route
- **Start:** ALU Rwanda
- **Destination:** Convention Center
- **Road length:** 3,400 metres
